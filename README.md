# Керівництво по проєкту Veda

Цей проєкт — простий застосунок на C++23, який можна складати й запускати як локально, так і в Docker-контейнері.

## 1. Локальна розробка (рекомендовано для розробки)

Для швидкого складання та запуску використовуйте CMake.

### Складання
```bash
cmake -S . -B build
cmake --build build
```

### Запуск
```bash
./build/veda
```

> CLion створює власні теки складання (`cmake-build-debug/`, `cmake-build-debug-docker/`) і працює
> через них. Вони прив'язані до машини, на якій згенеровані, і не потрапляють у git.

### Цикл розробки
1. Відредагуйте код у теці `src/`.
2. Виконайте команду складання.
3. Запустіть бінарний файл для перевірки.

## 2. Робота з Docker (для ізоляції та деплою)

Проєкт налаштований для роботи через Docker Compose.

### Складання та запуск
Якщо ви змінили код і хочете перескласти контейнер:
```bash
docker-compose up --build
```

Якщо код не змінювався, можна просто запустити:
```bash
docker-compose up
```

### Перевірка стану
`docker-compose.yml` перевизначає команду образу на `tail -f /dev/null`, тож контейнер працює
постійно і видно його у звичайному `docker ps`:
```bash
docker ps
```
Ви маєте побачити контейнер `veda-container` зі статусом `Up`. Щоб побачити й зупинені контейнери,
використовуйте `docker ps -a`.

### Зупинка та видалення контейнерів
```bash
docker-compose down
```

### Як зайти всередину контейнера
Якщо контейнер запущено (наприклад, з командою `tail -f /dev/null` у `docker-compose.yml`), ви можете зайти в нього через термінал:
```bash
docker exec -it veda-container bash
```

Якщо ви хочете запустити новий тимчасовий контейнер з інтерактивним доступом:
```bash
docker-compose run --rm veda-app bash
```

## Технічні деталі
- **Стандарт C++:** 23
- **Мінімальна версія CMake:** 3.20
- **Додаткові інструменти (у Docker):** Ninja, GDB, Node.js, Claude Code (CLI).
- **Файли:**
    - `src/main.cpp`: Точка входу.
    - `src/core/facade/`: `Facade` — зводить бібліотеки докупи.
    - `src/libs/`: `tensor`, `weights_loader`, `byte_pair_encoder`, `sampler` — складові рушія.
    - `CMakeLists.txt`: Єдиний плаский таргет `veda`; нові файли вписуються сюди вручну.
    - `Dockerfile`: Опис складання образу.
    - `docker-compose.yml`: Налаштування запуску контейнера.
    - `AGENTS.md`: Інструкції для AI-агентів (конвенції, пастки).
