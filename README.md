# Руководство по проекту Veda

Этот проект представляет собой простое приложение на C++23, которое можно собирать и запускать как локально, так и в Docker-контейнере.

## 1. Локальная разработка (рекомендуется для разработки)

Для быстрой сборки и запуска используйте CMake.

### Сборка
```bash
cmake --build cmake-build-debug
```

### Запуск
```bash
./cmake-build-debug/veda
```

### Цикл разработки
1. Отредактируйте код в папке `src/`.
2. Выполните команду сборки.
3. Запустите бинарный файл для проверки.

---

## 2. Работа с Docker (для изоляции и деплоя)

Проект настроен для работы через Docker Compose.

### Сборка и запуск
Если вы изменили код и хотите пересобрать контейнер:
```bash
docker-compose up --build
```

Если код не менялся, можно просто запустить:
```bash
docker-compose up
```

### Проверка состояния
Так как приложение завершает работу после вывода данных, в `docker ps` контейнер может не отображаться. Используйте:
```bash
docker ps -a
```
Вы должны увидеть контейнер `veda-container` со статусом `Exited (0)`.

### Остановка и удаление контейнеров
```bash
docker-compose down
```

### Как зайти внутрь контейнера
Если контейнер запущен (например, с командой `tail -f /dev/null` в `docker-compose.yml`), вы можете зайти в него через терминал:
```bash
docker exec -it veda-container bash
```

Если вы хотите запустить новый временный контейнер с интерактивным доступом:
```bash
docker-compose run --rm veda-app bash
```

## Технические детали
- **Стандарт C++:** 23
- **Минимальная версия CMake:** 3.20
- **Дополнительные инструменты (в Docker):** Ninja, GDB, Node.js, Claude Code (CLI).
- **Файлы:**
    - `src/main.cpp`: Основной код программы.
    - `Dockerfile`: Описание сборки образа.
    - `docker-compose.yml`: Настройка запуска контейнера.
